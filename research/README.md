# Research notes

Notes on PS2 games that were hard or impossible to emulate. One page per game
or game engine.

Each page has two kinds of content:

- **Background**: why the game broke and what fixed it. Written from public
  sources (bug reports, pull requests, the code). Sources are linked on each page.
- **Test results**: filled in only from real tests on real hardware by the
  maintainer of this fork. A results section stays empty until a test has been run.

The goal is to help anyone who works on these games later, in an emulator
or a static recompilation project.
